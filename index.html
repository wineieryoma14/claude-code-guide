0そもそも Claude Code ってなに？

ひとことで言うと、「AI に指示を出すと、自分のパソコン上で実際にファイルを作ったり編集したりしてくれるツール」です。

普通のAIチャット
（ChatGPT / Claude）		Claude Code
できること質問に答えてくれる
コードを「表示」してくれる		実際にファイルを作る
コードを書いて保存する
コマンドを実行する
イメージ「教えてくれる先生」「代わりに作業してくれるアシスタント」
プログラミングの知識がなくても使えます。日本語で「こういうの作って」と言えば、AIが全部やってくれます。

1ターミナルを開く

Claude Code は「ターミナル」という、文字だけで操作する画面を使います。
難しそうに見えますが、文字を打って Enter を押すだけなので安心してください。

Mac でターミナルを開く方法

  • キーボードの Command キー（⌘マークのキー）と Space キーを同時に押す
    → 画面の中央に検索バーが出てきます（「Spotlight検索」といいます）
  • 検索バーに 「ターミナル」 とキーボードで入力する
  • 「ターミナル」というアプリが表示されるので、Enter を押すか、クリックする
成功の確認：白い（または黒い）ウィンドウが開いて、文字が表示されていれば OK です。
あなたのMac名:~ ユーザー名$ のような表示が出ていれば成功です。
今後よく使うので、ターミナルを Dock に追加しておくと便利です。
Dock（画面下のアイコンが並んでいるバー）にあるターミナルのアイコンを右クリック → 「オプション」 → 「Dockに追加」

Windows で PowerShell を開く方法

Windows では「ターミナル」の代わりに 「PowerShell」 というアプリを使います。
やることは同じで、文字を打って Enter を押すだけです。

  • 画面の一番下にある タスクバー（横長のバー）の中にある 検索ボックス（虫眼鏡アイコン）をクリックする
    → もし検索ボックスが見当たらない場合は、キーボードの Windows キー（窓のマーク）を押してください
  • 検索ボックスに 「PowerShell」 と入力する
  • 「Windows PowerShell」というアプリが表示されるので、クリックして開く
「管理者として実行」は選ばないでください。
普通にクリックして開けば大丈夫です。「管理者として実行」は今は使いません。
成功の確認：青い背景のウィンドウが開いて、
PS C:\Users\あなたの名前> のような表示が出ていれば成功です。
今後よく使うので、タスクバーにピン留めしておくと便利です。
タスクバーにある PowerShell のアイコンを右クリック → 「タスクバーにピン留めする」

2Node.js をインストールする

Claude Code を動かすために必要なソフトです。最初に1回入れるだけで、あとは触る必要はありません。

まず、すでに入っているか確認する

ターミナル（PowerShell）に以下をそのままコピペして Enter を押してください：

node -v
v18.0.0 以上の数字が表示された場合 → すでに入っています！次のステップに進んでください。
command not found や 'node' は、...認識されていません と表示された場合 → まだ入っていません。下の手順でインストールしてください。

Node.js のインストール手順（Mac）

方法A：Homebrew を使う場合（おすすめ）

まず Homebrew（Mac用のソフト管理ツール）が入っているか確認します。ターミナルに以下をコピペして Enter：

brew -v

バージョン番号が表示されたら、Homebrew は入っています。次のコマンドをコピペして Enter：

brew install node

数分かかりますが、何も操作しなくて大丈夫です。勝手に進みます。

方法B：Homebrew が入っていない場合

brew -v で command not found と出た場合は、先に Homebrew を入れます。
以下を1行まるごとコピペして Enter：

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

途中で「パスワードを入力してください」と出たら、Mac のログインパスワード（Mac を起動した時に入力するパスワード）を入力してください。

パスワード入力中は画面に何も表示されません。これは正常です。「打てていないのかな？」と思うかもしれませんが、ちゃんと入力されています。打ち終わったら Enter を押してください。
Homebrew のインストールが途中で止まる・エラーが出る場合
Mac の環境によっては、上のコマンドだけではうまくインストールできないことがあります。
その場合は、以下の記事に書いてある手順を上から順番にやってみてください。同じ症状で解決できた報告があります。

→ Homebrew のインストール手順（Qiita の解説記事）

Homebrew のインストールが終わったら、続けて以下をコピペして Enter：

brew install node

Node.js のインストール手順（Windows）

Windows では、公式サイトからインストーラー（自動でインストールしてくれるファイル）をダウンロードして実行します。

  • ブラウザ（Edge や Chrome など）で以下のページを開く：
    https://nodejs.org/ja
    （Node.js の公式サイトです。日本語で表示されます）
  • ページに大きな緑色のボタンが2つあります。
    左側の「LTS」と書いてある方（推奨版という意味です）をクリックしてダウンロード
  • ダウンロードしたファイル（node-v○○-x64.msi のような名前）をダブルクリックして開く
  • インストール画面が出てきます。基本的に「Next」を押し続けるだけで大丈夫です。
    途中で「I accept the terms...」（利用規約に同意）にチェックを入れて、あとは Next → Next → Install
  • 「Finish」が表示されたらクリックして完了
インストール後は、PowerShell をいったん閉じてから開き直してください。
閉じないと、新しくインストールしたソフトが認識されないことがあります。
PowerShell のウィンドウ右上の × ボタンで閉じて、ステップ1の方法でもう一度開いてください。

インストールできたか確認する

node -v
v18.0.0 以上の数字が表示されたら成功です！
例：v22.5.1 → OK

2bGit をインストールする（Windows のみ）

Git は「ファイルの変更履歴を記録する仕組み」で、Claude Code を安全に使うために必要です。
Mac には最初から入っていますが、Windows には入っていないので、ここでインストールします。

まず、すでに入っているか確認する

PowerShell に以下をコピペして Enter：

git --version
git version 2.○○.○ のように表示された場合 → すでに入っています！次のステップに進んでください。
'git' は、...認識されていません と表示された場合 → まだ入っていません。下の手順でインストールしてください。

Git のインストール手順

  • ブラウザで以下のページを開く：
    https://gitforwindows.org/
  • 「Download」ボタンをクリックしてダウンロード
  • ダウンロードしたファイルをダブルクリックして開く
  • インストール画面が出てきます。すべて初期設定のまま「Next」を押し続けてください。
    （設定項目がたくさん出てきますが、何も変更しなくて大丈夫です）
  • 最後に「Install」→「Finish」をクリックして完了
インストール後は、PowerShell をいったん閉じてから開き直してください。
閉じないと Git が認識されません。

インストールできたか確認する

git --version
git version 2.○○.○ のように表示されたら成功です！

3Claude Code をインストールする

ターミナル（PowerShell）に以下をそのままコピペして Enter を押してください：

npm install -g @anthropic-ai/claude-code

2〜3分かかることがあります。画面にいろいろ文字が流れますが、何も操作しなくて OK です。
文字が流れ終わって、入力待ちの状態に戻ったら完了です。

もし「permission denied」というエラーが出た場合（Macのみ）：
「あなたには権限がありません」という意味のエラーです。
代わりに以下をコピペして Enter してください： 
sudo npm install -g @anthropic-ai/claude-code
パスワードを聞かれたら、Mac のログインパスワードを入力して Enter（画面に文字は表示されませんが正常です）。
もしエラーが出た場合（Windows）：
PowerShell を閉じて、「管理者として実行」で開き直してください。

やり方：タスクバーの検索で「PowerShell」と入力 → 「Windows PowerShell」を右クリック → 「管理者として実行」を選択

開いたら、もう一度同じコマンドを実行してください： 
npm install -g @anthropic-ai/claude-code

インストールできたか確認する

claude --version
バージョン番号が表示されたら成功です！
例：1.0.xx のような数字が出ればOK。
ここまでのチェックポイント

node -v でバージョンが出る → OK
git --version でバージョンが出る → OK
 claude --version でバージョンが出る → OK
両方全部出ていれば、インストールは完了です！

4Anthropic のアカウントを作る（課金設定）

Claude Code を使うには、Anthropic（クロード を作っている会社）のアカウントが必要です。
ここだけはターミナルではなく、普段使っているブラウザ（Safari や Chrome など）で作業します。

  • ブラウザで console.anthropic.com を開く
  • 「Sign Up」（新規登録）からアカウントを作成する（メールアドレスで登録できます）
  • ログインしたら、画面の左側にあるメニューから 「Billing」（日本語だと「請求」）をクリック
  • クレジットカードの情報を登録する
  • 「Add Credits」（クレジットを追加）などから $5〜$10 程度チャージする（最初はこれで十分です）
クレジットカード登録でエラーが出て先に進めない場合
「コンソールは一時的に利用できません」のようなエラーが出る場合は、ブラウザの自動翻訳が原因の可能性が高いです。

Google Chrome などのブラウザには、英語のページを自動的に日本語に翻訳する機能がありますが、この翻訳が入っていると、支払い画面がうまく動かないことがあります。

対処法：
ブラウザの画面上部、アドレスバー（URLが表示されているところ）の右のほうに、翻訳のアイコン（地球のようなマーク）が出ている場合は、それをクリックしてください。
そして 「翻訳しない」 や 「原文のページを表示」 を選んでください。

英語のままの画面でカード情報を入力すれば、正常に登録できます。
カード番号・有効期限・セキュリティコードの入力欄は、英語でも見た目で分かるので大丈夫です。
料金のイメージ：
Claude Code は使った分だけ料金がかかります（月額ではありません）。
普通に使って1日あたり数十円〜数百円程度です。
最初に $5（約750円）チャージしておけば、しばらく練習できます。
ここを飛ばすと、Claude Code を起動した時に「認証エラー」や「API key が無い」というエラーが出ます。
必ずクレジットカード登録とチャージを済ませてから次に進んでください。

5Claude Code を起動する

いよいよ起動です。コマンドを順番に実行してください。
1つ実行するごとに Enter を押して、画面が落ち着いてから次を実行してください。

5-1. 練習用のフォルダを作る

以下をコピペして Enter：

mkdir ~/my-first-project
mkdir は「フォルダを作る」コマンドです。あなたのホームフォルダ（Macの中の自分の場所）に「my-first-project」というフォルダが作られます。
mkdir $HOME\my-first-project
mkdir は「フォルダを作る」コマンドです。あなたのユーザーフォルダの中に「my-first-project」というフォルダが作られます。

5-2. そのフォルダに移動する

cd ~/my-first-project
cd $HOME\my-first-project
cd は「移動する」コマンドです。作ったフォルダの中に入ります。

5-3. Git を初期化する

git init
これ、超重要です。絶対にやってください。
Git は「変更履歴を記録する仕組み」です。
もし Claude Code が間違った変更をしても、Git があれば元に戻せます。
Git がないと、壊れたファイルを元に戻す方法がありません。
家の火災保険みたいなもので、「入れておいてよかった」と思うタイミングが必ず来ます。
Initialized empty Git repository と表示されたらOKです。

5-4. Claude Code を起動！

claude
  • 初回は、ブラウザが自動的に開きます（ターミナルとは別のウィンドウが出てきます）
  • Anthropic のログイン画面が出るので、ステップ4で作ったアカウントでログインしてください
  • 「許可しますか？」のような画面が出たら 「許可」 を押す
  • ブラウザの方は閉じてOKです。ターミナル（PowerShell）に戻ると、入力待ちの画面になっています
ターミナルに > のような入力待ちの表示が出たら、起動成功です！
ここに日本語で指示を打ち込めば、AIが作業を始めてくれます。
ここまでのチェックポイント

ターミナル（PowerShell）で Claude Code が起動して入力待ちになっている → 準備完了！
ここから先は、使い方を学んでいきましょう。

6CLAUDE.md を作る（AI への指示書）

CLAUDE.md は「Claude Code への設定ファイル」です。
「このプロジェクトではこうしてね」というルールを書いておくと、Claude Code が毎回それに従って動いてくれます。

なぜ必要？

CLAUDE.md がない場合CLAUDE.md がある場合
毎回「日本語で書いて」と言わないといけない自動的に日本語で対応してくれる
いきなりファイルを変更されることがある確認してから変更してくれる
何のプロジェクトか分からず的外れな回答が来るプロジェクトを理解した上で対応してくれる

作り方（超簡単）

Claude Code が起動している状態で、以下をそのままコピペして Enter してください：

このプロジェクトのCLAUDE.mdを作って。内容は以下の通り：
- 日本語で対応してください
- 初心者なので、分かりやすく説明してください
- ファイルを変更する前に必ず何をするか説明してください
- 一度にたくさんの変更をせず、1つずつ確認しながら進めてください

Claude Code が「ファイルを作成します」と聞いてくるので、キーボードで y（ワイ）を押して Enter してください。

プロジェクトフォルダに CLAUDE.md というファイルができたら成功です！
これで次回からClaude Codeがあなた向けに動いてくれます。
CLAUDE.md は後からいくらでも変更できます。使いながら「こういうルールも追加したいな」と思ったら、Claude Code に「CLAUDE.md にこのルールを追加して」と言えば OK です。

7指示の出し方を覚える（ここが一番大事）

Claude Code は指示の出し方で結果が大きく変わります。
ここをちゃんと押さえるだけで、「使えない…」から「めっちゃ便利！」に変わります。

NG と OK の比較

NG：曖昧な指示
いい感じのサイト作って

→ 何を作ればいいか分からず、
自分が思ってたのと全然違うものが出てきます。

OK：具体的な指示
index.html を作って。
タイトルは「自己紹介」。
名前・趣味・好きな食べ物を
箇条書きで表示して。

→ 具体的なので、
期待通りのものが出てきます。

覚えておくべき指示のコツ 4つ

コツ具体例
1. 何を作るかをはっきり言う 「HTMLファイルを1つ作って」
「Pythonのスクリプトを書いて」
2. 中身を具体的に書く 「見出しは"自己紹介"にして」
「名前と趣味を箇条書きで」
3. 一度に1つだけ頼む まず1つ作る → 確認 → 次を頼む
（10個まとめて頼まない）
4. 違ったらすぐ言い直す 「そうじゃなくて、こうして」
「色を赤じゃなくて青にして」
一番大事なのは3番目です。
「Webサイト全部作って」と一気に頼むのではなく、
「まずトップページを作って」→ 確認 → 「次にお問い合わせページを作って」
と、小さく区切って頼むのがコツです。

9安全に使うためのルール

絶対に守ってほしい3つのルール

ルール1：必ず Git 管理されたフォルダで使う
git init を実行したフォルダの中でだけ使ってください。
Git がないフォルダでファイルを壊されたら、元に戻す方法がありません。
ルール2：確認画面は必ず読んでから許可する
Claude Code が「ファイルを変更します」「コマンドを実行します」と聞いてきたら、
何をしようとしているか読んでから y を押してください。
よく分からない場合は n で拒否して、「もっと詳しく説明して」と聞いてください。
ルール3：大事なファイルがあるフォルダでいきなり使わない
まずは練習用フォルダ（my-first-project）で慣れてから、
本番のプロジェクトで使い始めてください。

「やばい、変なことされた！」と思ったら

落ち着いて、以下を順番にやってください：

  • まず /exit と入力するか、キーボードの Ctrl キーと C キーを同時に押して、Claude Code を終了する
  • ターミナル（PowerShell）で以下を打って、何が変わったか確認する： 
    git diff
    変更された内容が赤と緑の文字で表示されます。
  • 元に戻したい場合は、以下を実行する： 
    git checkout .
    これですべての変更が元に戻ります。
だから Git が大事なんです。Git さえ入れておけば、いつでも安全に元に戻せます。

10実際に練習してみよう

ここまでの設定が終わったら、実際に Claude Code を使ってみましょう。
以下の3つを順番にやってみてください。

練習1 : 自己紹介ページを作る

Claude Code に以下をそのままコピペしてください：

index.html を作ってください。内容は以下の通りです：
- ページのタイトルは「自己紹介」
- 名前は「（自分の名前）」
- 趣味は「（自分の趣味）」
- 好きな食べ物は「（好きな食べ物）」
- これらを箇条書きで表示してください
- 見た目はシンプルで読みやすい感じで

（自分の名前）などは自分の情報に書き換えてください。

できたら確認：ターミナル（PowerShell）をもう1つ開いて以下を実行：

open ~/my-first-project/index.html
start $HOME\my-first-project\index.html

ブラウザでページが表示されたら成功です！

練習2 : ファイルを修正する

Claude Code に以下を入力：

さっき作った index.html の趣味の部分を「映画鑑賞」に変えてください

ブラウザを更新（F5キーか、Command + RCtrl + R）して、変わっていたら成功！

練習3 : ページを追加してリンクでつなぐ

Claude Code に以下を入力：

about.html を新しく作ってください。
内容は「私について」の詳しいプロフィールページです。
そして index.html から about.html にリンクで飛べるようにしてください。

ブラウザでリンクをクリックして、ページが移動したら成功！

3つの練習ができたら、基本はマスターです！

「ファイルを作る」「修正する」「複数ファイルを連携させる」
この3つができれば、あとは応用していくだけです。

11よくあるエラーと対処法

「command not found: claude」 または「'claude' は、...認識されていません」と出る

原因：Claude Code がインストールされていないか、失敗しています。

対処：以下をもう一度実行してください：

npm install -g @anthropic-ai/claude-code

それでもダメなら：

sudo npm install -g @anthropic-ai/claude-code

それでもダメなら、PowerShell を「管理者として実行」で開き直してから再実行してください。

「command not found: node」 または「'node' は、...認識されていません」と出る

原因：Node.js がインストールされていません。

対処：ステップ2に戻って Node.js をインストールしてください。

Windows の場合、インストール後に PowerShell を閉じて開き直すのを忘れていませんか？

「command not found: brew」と出る（Mac のみ）

原因：Homebrew がインストールされていません。

対処：以下を実行してから brew install node を実行：

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

うまくいかない場合は、こちらの記事も参考にしてください。

認証エラー / API key が無い

原因：Anthropic のアカウント設定が完了していません。

対処：console.anthropic.com にログインして、以下を確認：

  • クレジットカードが登録されているか
  • クレジット（残高）があるか
クレジットカード登録画面で「一時的に利用できません」と出る

原因：ブラウザの自動翻訳が悪さをしています。

対処：ブラウザの翻訳をオフにして、英語のまま操作してください。
詳しくはステップ4の注意書きを確認してください。

「permission denied」と出る（Mac のみ）

原因：コマンドを実行する権限がありません。

対処：コマンドの前に sudo をつけてください。例：

sudo npm install -g @anthropic-ai/claude-code

パスワードを聞かれたら Mac のログインパスワードを入力（画面には文字が表示されませんが、ちゃんと入力されています）。

Claude Code がフリーズした / 反応しない

対処：キーボードの Ctrl キーと C キーを同時に押して一度終了し、もう一度 claude と入力して起動してください。

ターミナルに「(END)」と表示されて何もできない

対処：キーボードの q（キュー）を押してください。元の画面に戻ります。
これは「表示が長いので、スクロールして見てね」モードに入っている状態です。q で抜けられます。

12慣れてきたら次にやること

基本操作に慣れたら、Claude Code でこんなこともできます：

やりたいことClaude Code への指示の例
データを自動で整理したい「このCSVファイルを読み込んで、売上順に並べ替えるPythonスクリプトを作って」
簡単なWebツールを作りたい「テキストを入力したら文字数をカウントしてくれるHTMLを作って」
コードの意味を知りたい「このファイルの内容を日本語で説明して」
エラーを解決したい「このエラーが出た。原因と直し方を教えて：（エラーメッセージ貼り付け）」
大事なのは「小さく頼む → 確認する → 次を頼む」のサイクルを回すこと。
一気に全部やらせようとせず、一歩ずつ進めていきましょう。
慣れてくると、だんだん大きなタスクも任せられるようになります。

スターターキットもあります

この入門ガイドには「claude-code-starter」フォルダがセットでついています。
このフォルダで Claude Code を起動すると、
初心者向けの案内が自動的に始まります。

1. claude-code-starter フォルダをコピーして好きな場所に置く
2. ターミナル（PowerShell）で cd claude-code-starter で移動
3. claude で起動 → 自動で案内が始まります
